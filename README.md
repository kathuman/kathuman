## 🚀 Live deployments

### [Estay Dynamics](https://kathuman.github.io/estay-dynamics/) — consulting practice site
System dynamics and network optimization for supply chains, with two interactive research tools built in:

- **[Global Disruption Atlas](https://kathuman.github.io/estay-dynamics/atlas/)** — an interactive 3D globe of a live supply chain network: ports, factories, and corridors; live-style disruption signals (weather, strikes, geopolitical); scenario overlays (reroute, buffer, alternate-source); country borders and names; and CSV import to plot your own network.
- **[DDRA — Dynamic Cyber-Risk Model](https://kathuman.github.io/estay-dynamics/ddra/)** — a five-stock system dynamics model of the attack-defence loop in a cyber-physical ship ballast system. Move the sliders and watch detection delay decide containment vs. failure.

Repo: [kathuman/estay-dynamics](https://github.com/kathuman/estay-dynamics)
